# VEVÈ: The Resonance

Unity 6000.3.10f1 vertical slice for Milestone 1.

## Build the verification scene

1. Open this folder with Unity Hub.
2. In Unity, run **VEVE > Build Milestone 1 Scene**.
3. Open `Assets/Scenes/VEVE_Milestone1.unity` and press Play.

Controls: WASD, Left Shift, mouse, left mouse button, R to reload.

The scene builder creates an outdoor test area, a concrete building, wood cover,
an operator with weighted acceleration, a deterministic hitscan carbine, a
localized-damage enemy, basic perception AI, and a diegetic-style field readout.
Material resistance is data-driven through `Ballistics`.

The installed Unity Editor currently requires activation before batch-mode
validation or scene generation can run.
